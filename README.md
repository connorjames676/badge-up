# BadgeUp

BadgeUp is a challenge-based community platform built for a Web Application Development module. Coaches can create time-limited challenges, participants can join them and upload evidence of progress, and users can interact through likes and comments.

## Features

- User registration, login, password reset, and account management
- User profiles with biographies, profile images, badges, and activity history
- Create, edit, and manage challenges
- Join and leave challenges
- Dashboard for active, upcoming, and past challenges
- Submit challenge attempts with optional image evidence
- Coach approval of attempts
- Likes and comments on challenge attempts
- Badges linked to participants and challenges

## Built With

- PHP
- Laravel
- Laravel Breeze
- Laravel Livewire
- Tailwind CSS
- Alpine.js
- Vite
- SQLite / MySQL
